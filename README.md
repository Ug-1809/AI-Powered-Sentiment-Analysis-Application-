# AI-Powered-Sentiment-Analysis-Application
Developed an AI driven sentiment analysis application using Spring Boot and Spring AI and Integrated Large Language Models (LLMs) to analyse customer feedback and classify sentiment as Positive,Negative
Designed Rest APIs for submitting feedback and retrieving sentiment analysis results and applied prompt
engineering techniques to improve response quality and built a responsive frontend using React and Vite to
capture user feedback and display sentiment analysis results in real time
Techstack used : Java, Spring Boot, REST API, Spring AI, OpenAI
